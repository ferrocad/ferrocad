### 2.1 The grid-overlay probe (`../grid-overlay`, `25bbbe0`)

A third-party Coin/GLSL addon was audited as a minimal bring-up
([`grid-overlay-bringup.md`](grid-overlay-bringup.md)). It is **not a workbench**
(no `Workbench`, no `addWorkbench`, no toolbar append; `package.xml` calls it a
"global toolbar command"), but it is a compact Coin/shader fixture: 717 lines of
Python, 148 lines of GLSL, 14 Coin classes, no `Part`, no `Draft`, no `.ui` files.

Three results matter beyond the addon:

- **Its shader cannot run as authored.** The GLSL is `#version 120` with
  `gl_Vertex`/`gl_ModelViewMatrix`/`gl_FragColor`/`gl_FragDepth`; naga 29 accepts only
  440/450/460, and its `glsl-in` feature is not compiled. The math ports; the shader
  needs a WGSL rewrite (est. 150–200 lines).
- **Our Coin surface has a real compatibility bug.** `SO_SWITCH_ALL` is `-2` in
  `ferrocad_inventor` (`node.rs:25`), but Coin's value is `-3` (`SO_SWITCH_INHERIT` is
  `-2`). Any script that hardcodes `-3` — this addon does, twice — falls into the
  `n if n < 0 => {}` arm in `compile.rs:130` and draws nothing, silently.
- **Class gaps, verified:** `SoFaceSet`, `SoDepthBuffer`, `SoLightModel`,
  `SoFragmentShader`, `SoVertexShader`, `SoShaderProgram`, `SoShaderParameter1f/3f/`
  `Array1f` are all absent; `SoPickStyle` is only a doc-comment mention, not a class.
  `setNum`, `removeChild`, `set("write FALSE")` and `renderCulling` are also missing.

## 4. Open decisions, and what the design notes recommend

1. **Qt.** Bundle it (A), emulate PySide over gpui (B), rewrite Draft's GUI (C), or
   the split plane (D): native grid/snap + a `.ui` loader + a micro-shim.
   [`qt-strategy.md`](qt-strategy.md) recommends **D**, on measured evidence —
   4 Qt subclasses, 0 `paintEvent`, 0 `QGraphics*`, and a 24-method form contract for
   the six core panels.
2. **Part / Draft.** Independent (A), Draft inside Part (B), or layered composition
   (C) with orthogonal Rust crates recombined in the facades.
   [`part-draft-layering.md`](part-draft-layering.md) recommends **C**: a new leaf
   `ferrocad_curves`, `ferrocad_geom` keeping its B-Rep meaning, and `ferrocad_part`
   as the document layer that re-exports both. No parent crate.
3. **Order.** Draft first, or SimpleCAD first as the proving ground.
   [`simplecad-bringup.md`](simplecad-bringup.md) recommends **SimpleCAD first** on a
   shared `Part` kernel slice, with Draft's headless side in parallel and its GUI
   blocked on decision 1.
4. **Shader authoring, Coin completeness, and the second grid.** Decided on
   2026-10-21 as three tracks: **(1)** fork the addon and port to WGSL (or make it a
   thin client), **(2)** add the missing `So*` surface and fix the compatibility bugs,
   **(3)** expose a semantic `FreeCAD.Grid` API, which is the preferred product
   direction because appearance is almost all the overlay does.
   [`grid-overlay-plan.md`](grid-overlay-plan.md) specifies the API surface, the
   WGSL/fork strategy, and the G0–G6 staging (*est.* 7.5–11 engineer-days).
