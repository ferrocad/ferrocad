## P0 — split the serializers (unblocks honest conformance tracking)

Full breakdown: [`tasks/format-serializers.md`](tasks/format-serializers.md).

The decision: native JSON gets `.ferrocad`; upstream `.FCStd` is the
conformance-tracked import/export format. Selection is explicit by suffix, never by
content sniffing, so our own format can change without moving the conformance number.

- [x] **F1 — dispatch split.** `DocumentFormat`, suffix parsing, and explicit
      native/FCStd backends for `openDocument`, `load`, `saveAs`; `has_zip_magic` is
      gone and the `.FCStd` JSON placeholder is named. **Landed 2026-10-23.**
- [x] **F2 — native envelope.** `{"format":"ferrocad","version":1,…}` with serde
      defaults, so bare files written today still load. **Landed 2026-10-23.**
- [x] **F3 — migrate our artefacts.** Workflows, examples, tests and the two
      generated user pages now use `.ferrocad`; upstream `.FCStd` fixtures stay
      untouched. **Landed 2026-10-23.**
- [x] **F4 — reader gaps.** `PropertyLength`/`Angle`, `PropertyEnumeration`,
      `PropertyLinkSub`, `PropertyLinkList`/`LinkSubList`, `PropertyPythonObject`,
      expressions and the status bitmask are read. **Landed 2026-10-23.**
- [x] **F5 — FCStd ZIP writer, direct-call API.** `write_fcstd`/`encode_fcstd` emit
      `Document.xml` + `PartShapeN.brp`; not wired to `saveAs`. **Landed 2026-10-23.**
- [x] **F6 — writer breadth.** Shape lists (one `.brp` member per entry via
      `ExtensionData::fcstd_members`), expressions, `ObjectDeps`, statuses and
      `_Property` placeholders, extensions, and a dropped-value report for
      `python_state`. **Landed 2026-10-23.**
- [x] **F7 — `GuiDocument.xml`.** `Visibility`, `Transparency`, `ShapeColor`,
      `DiffuseColor` (with the packed `DiffuseColorN` members) and `DisplayMode`.
      **Landed 2026-10-23.**
- [x] **F8a — read payloads and `GuiDocument.xml`.** `.brp` and shape-list members
      restore through `property_types::restore_extension`, and the GUI document restores
      `Visibility`/`Transparency`/colours/`DisplayMode`. **Landed 2026-10-23.**
- [x] **F8 — switch.** `saveAs(.FCStd)` writes the real ZIP container; the placeholder
      is gone, unsupported property types error by name, and the archive magic is
      asserted. **Landed 2026-10-23.**

## P1 — Part: naming, links, and the remaining conformance gaps

The owner's framing (2026-10-23): the last FreeCAD/Part gap is **TNP / Links / FCStd**,
and the three are intertwined. The design response is explicit: naming is a lineage
layer, not a geometry-kernel concern.

- [x] **Lineage S1/S2 — vocabulary and layer.** `crates/ferrocad_lineage` owns the
      payload-generic vocabulary plus `Lineage<T>`, `ReverseMap`, `MapVersion` and a
      `NamePolicy`; `ferrocad_geom` re-exports it over `Shape`. 19 tests, no consumer
      yet, no behaviour change. **Landed 2026-10-23.**
- [x] **Lineage S4 — provenance breadth.** The OCCT backend now reports both
      operands and faces/edges/vertices, with operand id, kind and ordinal; names stay
      positional and `ElementMapVersion` is untouched. 3 golden histories. **Landed
      2026-10-23.**
- [x] **Lineage S3 — store the map with the shape.** `ShapeProperty` persists a
      versioned lineage envelope (legacy raw BREP still loads), boolean containers fold
      the backend history, and an empty history stays empty. 4 tests. **Landed
      2026-10-23.**
- [x] **Lineage S5 — resolve through the map.** Part resolves stored sub-element names
      through the shape's `Lineage` first (positional fallback only when no lineage
      exists); a retired name fails instead of moving to another edge. **Landed
      2026-10-23.**
- [x] **Lineage S6a — carry and expose the reverse map.** `Shape` carries the stored
      lineage; `ElementReverseMap` returns `{output: [inputs]}`. The compound cuts now
      measure **12** and **30** keys (upstream asserts 20/47); the remaining gap is the
      naming/alias policy, not fabricated data. `ElementMap`/`ElementMapVersion` stay
      empty. **Landed 2026-10-23.**
- [ ] **Lineage S6b.** Persist the map in `.FCStd` and close the 12→20 / 30→47 gap once
      upstream's naming form is understood. This is the remaining path to the two
      compound-cut tests; do not enable `ElementMapVersion` until the map sizes are
      reproduced (the tests assert 52/58/26/10/9/24 once it is non-empty).
- [x] **Links L0–L2.** Full note: [`tasks/links.md`](tasks/links.md).
      `isLink`/`getLinkedObject`/`getElementIndex` and dotted `getSubObject` paths are
      in; `App::Link` has the shared property base and a Part-side `execute` that
      transforms the target's shape. 5 Rust tests. **Landed 2026-10-23.**
- [x] **Links L3 — element semantics.** `App::LinkElement` (with the legacy
      `Part::LinkArrayElement` alias) is generated when `ShowElement` is set, carries a
      placement and a composed shape, is listed in `ElementList`, and resolves through
      `getSubObject("Link.Element3")`; collapsing removes the children. **Landed
      2026-10-23.**
- [x] **Links L4 — scale and containers.** A general affine transform carries a
      non-uniform `ScaleVector`; `App::LinkGroup`/`LinkList` expand their members; and
      `LinkMode`/`LinkCopyOnChange` are stored (the copy modes stay inert without a
      clone facility). **Landed 2026-10-23.**
- [ ] **Links L5.** Resolve `LinkSub` and element sub-paths through the lineage map at

      positional names.
- [x] **Link-array gaps — closed.** The four files are **24/24** (was 19/27): the
