## P0 — split the serializers (unblocks honest conformance tracking)

Full breakdown: [`tasks/format-serializers.md`](tasks/format-serializers.md).

The decision: native JSON gets `.ferrocad`; upstream `.FCStd` is the
conformance-tracked import/export format. Selection is explicit by suffix, never by
content sniffing, so our own format can change without moving the conformance number.

- [ ] **F1 — dispatch split.** `DocumentFormat`, suffix parsing, and explicit
      native/FCStd backends for `openDocument`, `load`, `saveAs`; delete
      `has_zip_magic`; keep the named JSON placeholder for `.FCStd` writes until the
      writer lands. *Lowest risk; do this first.*
- [ ] **F2 — native envelope.** `format`/`version` with serde defaults, so bare files
      written today still load.
- [ ] **F3 — migrate our artefacts.** `tools/workflows/`, `examples/`, tests and the
      two generated user pages from `.FCStd`-as-JSON to `.ferrocad`; upstream
      `.FCStd` fixtures stay untouched.
- [ ] **F4 — reader gaps** the writer needs: `PropertyLength`, `PropertyAngle`,
      `PropertyEnumeration`, `PropertyLinkSub`, expressions, `PropertyPythonObject`.
- [ ] **F5 — FCStd ZIP writer, direct-call API:** `Document.xml` + `.brp` for
      `Part::PropertyPartShape`, not yet wired to `saveAs`.
- [ ] **F6 — writer breadth:** shape lists, `ObjectDeps`, proxies/`python_state`, and
      the no-silent-loss policy.
- [ ] **F7 — `GuiDocument.xml`:** `Visibility`, `Transparency`, `ShapeColor`,
      `DiffuseColor`, `DisplayMode`; must be green before the switch.
- [ ] **F8 — switch.** `saveAs(.FCStd)` emits ZIP; delete the placeholder; assert the
      ZIP magic in CI. Highest risk: verify against real FreeCAD first.

## P1 — Part: naming, links, and the remaining conformance gaps

The owner's framing (2026-10-23): the last FreeCAD/Part gap is **TNP / Links / FCStd**,
and the three are intertwined. The design response is explicit: naming is a lineage
layer, not a geometry-kernel concern.

- [ ] **Lineage layer (TNP).** Full note:
      [`architecture/lineage-and-naming.md`](architecture/lineage-and-naming.md).
      The kernel supplies `Modified`/`Generated`/`IsDeleted` provenance (already
      bridged); a separate `ferrocad_lineage` crate owns identity, naming policy,
      versioning, collisions and persistence; Part is the frontend that records the
      parametric history. Start non-breaking: move `History`/`ElementMap` behind the
      new boundary and re-export, then add reverse maps and naming. This is the only
      path to the two compound-cut tests, and it must not enable
      `ElementMapVersion` until the exact upstream map sizes are reproduced (the
      upstream tests assert 52/58/26/10/9/24 once the version is non-empty).
- [ ] **Links.** Full note: [`tasks/links.md`](tasks/links.md). `App::Link` currently
      has `LinkedObject`/`setLink`/`getParent` and a view object but no shape,
      placement, scale, element-list or copy-on-change semantics. Start with
      `isLink`/`getLinkedObject`/`getSubObject`, a shared link property base, then
      element lists; sub-element resolution depends on the lineage layer.
- [ ] **Link-array gaps (8 failures).** Property-change hooks (reject suppressing
      every element; reject writing element flags while `ShowElement` is set), the
      execute-error text in `getStatusString`, recompute-on-restore, and the one-ulp
      quaternion difference in the Circular save/restore check. See the closed record
      for the exact cases; the four files are 19/27 passing.
- [ ] **Compound cuts and the sweep assertion.** `testPartCompoundCut1`/`2` need a
      real `ElementReverseMap` (the lineage layer). `testAppPartMakeSweepSurface`
      asserts a legacy `GeomFill_Pipe` bug; leave it documented, do not distort
      geometry.
- [ ] **Load errors.** `TestPartMirror.py` needs `Draft.make_clone`; `TestPartApp.py`
      pulls it in and also needs `Sketcher::SketchObject`. Both are real bring-up
      work, not harness fixes.
- [ ] **Shared Part kernel breadth** — the remaining surface from the M0–M5 plan
      (see the closed record for what landed); it unblocks Draft, SimpleCAD and the
      shadows producer.
- [ ] **SimpleCAD S0** — wire its audit into the harness *before* more `Part` code,
      so the baseline is a number
      ([`workbenches/simplecad-bringup.md`](workbenches/simplecad-bringup.md)).
- [ ] **Shadows producer** — once `Part` can supply bounds, fill the `Program`
      block's `shadow_data`/`shadow_count`; the shader loop and ABI exist.
- [ ] **Pin the upstream revision** before publishing any conformance number; record
      `git -C ../freecad-upstream rev-parse --short HEAD` with every report.
