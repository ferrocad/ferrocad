## P0 — split the serializers (unblocks honest conformance tracking)

Full breakdown: [`tasks/format-serializers.md`](tasks/format-serializers.md).

The decision: native JSON gets `.ferrocad`; upstream `.FCStd` is the
conformance-tracked import/export format. Selection is explicit by suffix, never by
content sniffing, so our own format can change without moving the conformance number.

- [x] **F1 — dispatch split.** `DocumentFormat`, suffix parsing, and explicit
      native/FCStd backends for `openDocument`, `load`, `saveAs`; `has_zip_magic` is
      gone and the `.FCStd` JSON placeholder is named. **Landed 2026-10-23.**
- [x] **F2 — native envelope.** `{"format":"ferrocad","version":1,…}` with serde
      defaults, so bare files written today still load. **Landed 2026-10-23.**
- [x] **F3 — migrate our artefacts.** Workflows, examples, tests and the two
      generated user pages now use `.ferrocad`; upstream `.FCStd` fixtures stay
      untouched. **Landed 2026-10-23.**
- [x] **F4 — reader gaps.** `PropertyLength`/`Angle`, `PropertyEnumeration`,
      `PropertyLinkSub`, `PropertyLinkList`/`LinkSubList`, `PropertyPythonObject`,
      expressions and the status bitmask are read. **Landed 2026-10-23.**
- [x] **F5 — FCStd ZIP writer, direct-call API.** `write_fcstd`/`encode_fcstd` emit
      `Document.xml` + `PartShapeN.brp`; not wired to `saveAs`. **Landed 2026-10-23.**
- [ ] **F6 — writer breadth:** shape lists, `ObjectDeps`, proxies/`python_state`, and
      the no-silent-loss policy.
- [ ] **F7 — `GuiDocument.xml`:** `Visibility`, `Transparency`, `ShapeColor`,
      `DiffuseColor`, `DisplayMode`; must be green before the switch.
- [ ] **F8 — switch.** `saveAs(.FCStd)` emits ZIP; delete the placeholder; assert the
      ZIP magic in CI. Highest risk: verify against real FreeCAD first.
