### 0.1 What the 2026-10-27 fifth fan-out changed

- **SimpleCAD S4.1 — the view facade.** `FreeCADGui.ActiveDocument.ActiveView` is a
  `View3DInventor` over the published view: `getPointOnScreen`, `getSize`,
  `getViewDirection`, `getCameraNode` (Coin's `SoCamera` vocabulary, perspective and
  orthographic), `getViewVolume`, `getField`, `addEventCallbackPivy`/
  `removeEventCallbackPivy`, `updateGui`, `fitAll` and `redraw`. A host publishes the
  camera and stage with `ferrocad_stage.set_view_camera`/`set_view_stage`; a headless
  script can publish the same values. `crates/ferrocad_stage_py/src/view.rs`,
  `camera.rs`, `python/FreeCADGui/__init__.py`.
- **S4.2 — ranked pick.** `getObjectsInfo` returns every distinct `(entity,
  sub-element)` under the pointer, nearest first, with `Document`/`Object`/`Component`/
  `x`/`y`/`z`; `getObjectInfo` is the first entry. An untagged or unselectable item is
  never reported.
- **S4.3 — the selection object.** `Gui.Selection` reads a shell-pushed snapshot
  (`_set`) and resolves it against the live document; `SelectionObject` exposes
  `Object`, `SubElementNames`, `PickedPoints`, `ObjectName` and `HasSubObjects`; writes
  update the snapshot and queue the operation for the shell (`_take_requests`).
- **Draft M4 import round.** `Quantity` compares equal to a bare number, `FreeCAD.
  getHomePath()` finds the `Mod` root from an imported workbench, and
  `TechDraw.projectToSVG` is callable, so Draft's DXF/SVG tests load and patch it. The
  round also preserves the derived wrapper from `Part::Feature.Shape` (a `Part.Wire`
  stays a wire), registers `Part::Prism`, and adds `Shape.fix`/`OrderedEdges`. Measured
  with `--files test_modification`: **31 passed / 0 failed / 2 errored** (from 22/1/10);
  the `--draft` group stays **44/0/0/0** because no further import module qualifies.
  `test_svg` moves to 3/0/6/1 and `test_draftgeomutils` to 2/4/4; the remaining errors
  are the `Shape.copy` wrapper, a missing `fixWire`, `Import.readDXF`, `Sketcher` and
  TechDraw.
- **Part API gap batch.** `Face.isPartOfDomain`, `Shape.fix`, `makeOffsetShape`,
  `defeaturing`, `makeParallelProjection`/`makePerspectiveProjection`, `makePipeShell`,
  `BSplineSurface.buildFromPolesMultsKnots` with the poles/knots/weights/
  multiplicities/degree accessors, `Geom*` `parameter`/`copy`/`toShape`, the
  `Ellipse`/`Circle` centre/location/axis setters, and `AngleXU`. The audit contract
  moves 220 → 248. `crates/ferrocad_occt/src/part_ops.rs` is the new OCCT-only seam.
- **Offscreen snapshots and user-doc images.** `ferrocad_wgpu::snapshot` renders a JSON
  scene through the normal offscreen path and encodes a deterministic PNG, with an
  explicit “no adapter” error. `tools/userdocs.py --capture` consumes the render specs
  the workflows record and writes `docs/user/images/` (the first two images are
  `first-model.png` and `toy-slab.png`); `--check` stays GPU-free and reads the
  committed PNGs. A capture without an adapter reports it and leaves the images alone.
- **Draft conformance harness.** `crates/ferrocad_part_py/tests/draft_conformance.rs`
  runs `tools/conformance.py --draft` in the same in-process image as the Part group,
  and `crates/ferrocad_part_py/tests/part_api_gaps.rs` pins the gap batch at the Python
  surface.
