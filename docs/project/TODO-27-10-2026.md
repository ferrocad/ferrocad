### 0.3 What the 2026-10-27 seventh fan-out changed

The round that followed the measurement rather than a task list. The dominant SimpleCAD
buckets were all “our reconstruction is wrong”, and one bug explained most of them.

- **`Geom2d.*.toShape(surface)` now lifts the curve onto the surface.** Only the B-spline
  branch projected; every analytic 2-D curve returned its `z = 0` image and merely
  *recorded* the surface. `fc_curve2d_on_surface` turns the planar edge's own curve into
  the pcurve and rebuilds it on the surface (`BRepBuilderAPI_MakeEdge(pcurve, surface)` +
  `BRepLib::BuildCurves3d`), which is upstream's `create3dCurve`. That alone cleared all
  16 “drawing leaves the surface”, the 5 seam-accuracy errors and a fitted-face bucket.
- **`Part.makeShell` sews when the naive shell is invalid**, as upstream's
  `makeElementShell` does (`BRepCheck_Analyzer` then `ShapeUpgrade_ShellSewing`). Six
  independently built faces were a shell with six unshared edge copies, so
  `isValid()`/`isClosed()` were false and `makeSolid` produced nonsense; that was the
  planar-reconstruction and mesh→CAD bucket.
- **`makeFace(..., 'Part::FaceMakerBullseye')` is a real face maker** (nesting by bbox and
  a point-in-face test, outer CCW, holes CW, a compound for disjoint regions) instead of
  “first wire is outer”, and `Part::FaceMakerSimple` exists. `Part.Face(wire)` now finds a
  surface from a wire whose edges already lie on one.
- **`CenterOfMass`/`PrincipalProperties` use upstream's regime** for a compound of faces
  (surface, not volume), which fixes the stud-placement buckets, and **`Shape.tessellate`
  returns doubles**, not the `f32` display positions, so a tessellated boundary can be
  welded back onto the wire.
- **Mesh analysis matches upstream.** Self-intersection counts positive-length
  intersections only (a vertex touch is not one), `getPlanarSegments` refits its plane as
  the region grows with no angular gate, `fixDegenerations` uses upstream's squared-length
  epsilon, and operations that keep the facet list keep the facet groups.
- **Property add/remove is undoable.** `Change::PropertySlot` records both sides, so
  removing a dynamic property and undoing restores it with its value, type and status —
  which closes SimpleCAD's `SC_Support` case. `ViewState` stores full materials rather
  than bare colours, so all six `Material` fields survive a `ShapeAppearance[i]`
  round-trip.
- **`flatmesh` exists** (`python/flatmesh`, pure Python): a rigid unfolding seed over the
  face's triangulation, a seam cut that splits the tube, and a spring relaxation run by
  `findFlatNodes(iterations, tolerance)`. Planar and developable faces unwrap exactly;
  doubly-curved ones are approximate and the docstring says so.
