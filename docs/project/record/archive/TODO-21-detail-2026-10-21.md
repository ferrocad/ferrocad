### 2.2 The four follow-up fixes

1. **Tool status and cancel.** `Tool::status()`/`cancel()`, `ToolStatus`, viewport
   `ViewportEvent::ToolState` with `Esc`/`Enter`/`cancel_tool`, and a shell strip under
   the viewport header with a **Cancel** button. Cancelling emits no
   `InteractionCommit`. Finishing the polyline does not yet commit geometry (later
   slice).
2. **Navicube/camera are Z-up.** The world is Z-up (grid on `z=0`, `Workplane::world`
   `u=+X, v=+Y, n=+Z`, OCCT). `TOP` is now `+Z`, the compass lies in `XY`, yaw orbits
   about `+Z`, and the sample camera is the Z-up isometric view. Docs updated
   (`axis-origin-grid.md`, `navicube*.md`). A rendered frame shows `T` on the top face.
3. **Renderer diagnostics + the black-screen race.** `FERROCAD_TRACE=1` / `--trace`
   logs the adapter, uncaptured errors and device loss, frames, cameras, program
   pipelines, group-2 binds, resizes and a readback black-frame probe. The zero-copy
   presenter now uses a **3-slot dma-buf ring**, reuses a slot only after the consumer's
   release (or a conservative distance), and repaints the last good frame on a skip.
4. **Provider metadata and switching.** `registerProvider` / `providers` /
   `activeProvider` / `setActiveProvider` in `FreeCADGui`, persisted under
   `BaseApp/Preferences/Mods`, with `activate`/`deactivate` hooks. Both grid mods declare
   `grid`; `Mods_Settings` switches them.

## 6. Unfinished work at close (carried to 2026-10-22)

### Renderer / viewport

- **Residual black frames.** They still occur, intermittently, **only with the
  WGSL/Coin grid**; the native grid does not reproduce them. The 3-slot ring reduces but
  does not eliminate them. Tracked in
  [`upstream-dmabuf-issue.md`](../../research/upstream-dmabuf-issue.md) and upstream issue #1. Capture
  one with `FERROCAD_TRACE=1` (`frame N: black`, presenter slot/reuse lines).
- **Shadows** are compiled and validated but `shadow_count = 0`; they need a
  document-bounds producer (Part/TopoShape), so they follow the `Part` kernel.
- **Program ABI is fixed**: an author can target the documented `Frame`/`Program`
  blocks but cannot invent a uniform name. Say "author shaders against the FerroCAD
  ABI", not "any Coin shader".
- **`compile_with` still panics** for callers outside the viewport (tests, navicube).
  The shell path is the non-fatal one (`compile_diagnostic`).
- **`--trace` does not cover the gpui surface path** (gpui owns it); the presenter
  fallback is logged instead.

### Grid / mods

- **External mod ingestion.** `ferrocad/ferrocad-grid-overlay` is a standalone repo at
  `3b376cb`. The next step is to ingest it (as a gitignored fetched mod or as a
  first-class provider) instead of maintaining the duplicate `mods/GridOverlayCoin`.
- **Duplicate WGSL.** The shader exists in `crates/ferrocad_wgpu/shaders/`,
  `mods/GridOverlayCoin/Resources/`, and the external repo. The external repo should
  become the single home; the crate copy is the reference for tests.
- **Provider choice is in-memory.** `ParamGet` is a shim, so the selected backend does
  not survive a restart.
- **Inactive commands remain visible.** Both grid commands appear; the losing one
  refuses. Hiding/disable-by-provider needs a shell-side filter (a Rust UI slice).
- **The registry is advisory.** A third-party mod that ignores `activeProvider` can
  still draw.
- **Per-document deactivation** is handled on the next activation because
  `FreeCADGui` has no document-deactivate slot.
- **Shadows in the external mod** are the same deferred knob.

### Toys / tools

- **Finishing the polyline does not commit geometry.** `Enter` ends the session without
  an `InteractionCommit`; committing a wire is a later slice.
- **Tool status is a strip, not a panel.** A richer tool panel/dialog is optional.

### Draft / Part / SimpleCAD

- **D0** (the five fixes) is not landed; **`SVGPath`/`Draft`/`offset`** still need
  `Part`.
- **`--draft` conformance group** does not exist in `tools/conformance.py`.
- **Shared `Part` kernel slice** is the critical path: `LineSegment`/`Circle`/`Arc`/
  `Edge`/`Wire`, then `Face`/`makePolygon`/`Compound`/solids.
- **SimpleCAD S0** (the audit baseline) is not wired into the harness.
- **Upstream is pinned informally.** `33adf61` is a moving target; record the revision
  with any number.
- **`QtSvg`** is absent from the system PySide6; decide whether it is required.

### Operational

  (`CARGO_BUILD_JOBS=2`), do not run two workspace-wide builds at once.
